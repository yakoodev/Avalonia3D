# TestScenes: как добавить свою модель

1. Скопируйте `*.gltf` (и связанные `*.bin`/текстуры) в эту папку.
2. Для текстур используйте относительные пути внутри glTF (например `textures/...`).
3. Перезапустите `Avalonia3D.Sandbox`.

## Что произойдёт автоматически

- Любой новый `*.gltf` в `Assets/TestScenes` автоматически появится в меню сцен как `Модель: <имя_файла>`.
- Для авто-сцен применяется дефолтный свет (2 источника), если модель не содержит источников света.
- После загрузки применяется авто-кадрирование камеры по world-bounds.

## Рекомендации

- Для наглядной проверки рендера используйте модели типа `DamagedHelmet`, `Lantern`, `BoomBox`.
- Если модель не видна, проверьте логи `Scene diagnostics` (число мешей, bounds, lights, позиция камеры).
