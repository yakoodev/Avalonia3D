## Solution Projects / Проекты решения

- `Avalonia3D` - основной движок: сцена, загрузка glTF, рендер-пайплайн, шейдеры, поведения, анимации.
- `Avalonia3D.Sandbox` - desktop UI для загрузки/переключения сцен и настройки графики в рантайме.
- `Avalonia3D.Tests` - xUnit-тесты на доменную логику, импорт, рендер-конфигурацию и интеграционные сценарии.
